RESEARCH RECORD

영상에서 지도로,
지도에서 공간지능으로.

가시화, 재구성, 이종 센서, 벡터 추출을 연결하는 다섯 가지 연구입니다.

01

WEB / RASTER PIPELINE

On-the-fly
Pan-sharpening

COG(Cloud Optimized GeoTIFF)와 WebGL을 결합해 브라우저에서 팬샤프닝을 가시화하는 방식을 다뤘습니다. 사전 생성·저장을 줄이고, 클라이언트 렌더링으로 다중 사용자 환경의 서버 연산 부담을 분산하는 구조입니다.

COGWebGLclient-side rendering
02

LEARNING / MAPPING VALIDATION

Satellite super-resolution,
tested for mapping.

위성영상 특화 딥러닝 초해상화 모델을 설계·학습하고, 생성 영상으로 RPC 오차 보정과 포인트 클라우드·DSM 생성을 위한 지도를 제작했습니다. 원본 영상 기반 결과와 비교해 정확도 유지 또는 향상을 검증했습니다.

03

MULTI-SENSOR / IMAGE TRANSLATION

Night sensing,
translated to daylight.

야간 라이다 강도·거리영상과 열적외영상을 주간 광학 영상으로 모의했습니다. CycleGAN, CUT, UNSB, CycleGAN-turbo를 비교했고, 시각적 분석과 SSIM·PSNR·UIQI 평가에서 CycleGAN이 구조와 색상 매핑에 가장 안정적인 결과를 보였습니다.

04

VECTOR EXTRACTION / EVALUATION

Buildings, made
measurable as polygons.

산업용 위성영상 데이터셋에서 Frame Field Learning, PolyWorld, HiSup을 비교했습니다. 새 라벨링 테스트셋과 AP, IoU, C-IoU, PoLiS, MTA 지표를 활용했으며, Frame Field Learning이 가장 우수한 객체 추출 성능을 보였습니다.

05

PATENT / 3D RECONSTRUCTION

Satellite imagery
into 3D space.

특허로 제안한 3차원 공간 재구축 시스템입니다. 스테레오 위성영상에서 AI로 지붕면을 추출하고, 수량에 따라 픽셀 분할 크기를 최적화합니다. 지상좌표·수직 입면으로 건물 메시를 만들고, 텍스처와 지형 메시를 병합합니다.
